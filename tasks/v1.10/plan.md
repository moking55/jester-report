## Overview

Studio อย่างเดียว (ไม่แตะ api): คลิกเซลล์ในตารางเพื่อเลือก แล้วปุ่ม toolbar ทำกับแถว/คอลัมน์ของเซลล์นั้น; ตารางเปล่ารวม/แยกช่องได้ (colspan);
แถวแบ่งคอลัมน์เลือกจำนวน 2/3/4; ขึ้น/ลงย้ายไป toolbar; แผงขวาเหลือค่าที่ต้องพิมพ์; ติดตั้ง Studio เป็นแอป (manifest + service worker บาง ๆ)
ไม่มี dependency ใหม่

## Architecture Decisions

- **ตารางเปล่ารับ colspan:** `gridDetail` เลิกปฏิเสธ `colspan`; ทุกแถวต้องรวม span เท่ากัน (ไม่เท่า = Custom Code เหมือนเดิม); `GridCell` มี `span`;
  edit ของตารางเปล่า (เพิ่ม/ลบคอลัมน์, เลื่อน) ทำงานกับ "คอลัมน์จริง" (นับ span): เพิ่มคอลัมน์ผ่ากลางช่องที่รวมอยู่ = ช่องนั้นกว้างขึ้นหนึ่ง span,
  ลบคอลัมน์ที่อยู่ในช่องรวม = ช่องนั้นแคบลง; เลื่อนคอลัมน์ที่คร่อมช่องรวมไม่ได้ (ปุ่มเทา). edit ใหม่: `gridMergeRight(row, col)`, `gridSplit(row, col)` — Vitest ครบทุกกรณี
- **เลือกเซลล์:** state `cell: { key, row, col }` ใน Workbench; คลิกครั้งเดียวในตาราง → `Frame` หา `td/th` ที่คลิกจาก event (ไม่ต้องเปลี่ยนการวาดตารางรายการ
  ที่เป็น HTML ดิบ) แล้วแปลงเป็นแถว/คอลัมน์จริง (`cellAt` pure function, นับ colspan); เซลล์ที่เลือกมีกรอบฟ้า (class ใน shadow DOM);
  ดับเบิลคลิกยังพิมพ์เหมือนเดิม; เปลี่ยนบล็อก/แก้ไฟล์จนเซลล์ไม่อยู่แล้ว = ล้างเซลล์
- **ปุ่มตามเซลล์** ต่อจาก `kindTools` ของ v1.9 (ctx มี `cell`) — ไม่มีเซลล์ = ทำที่ท้ายแบบ v1.9; ปุ่มที่ทำไม่ได้กับเซลล์นั้นเป็นสีเทา
- **จำนวนคอลัมน์ของแถว:** เพิ่ม = `addRowColumn` เดิม (ซ้ำ), ลด = `mergeColumns` คอลัมน์ท้ายเข้าคอลัมน์ก่อนหน้า (บล็อกไม่หาย) — มีอยู่แล้วทั้งคู่
- **PWA:** `app/manifest.ts` ของ Next (route แบบ dynamic อ่าน theme ที่ใช้อยู่ → `theme_color`/`background_color`); ไอคอน 192/512/maskable
  สร้างจาก `public/jester-logo.webp` ครั้งเดียวเป็น PNG ใน `public/icons/` (commit ไฟล์); `public/sw.js` เขียนมือ ~40 บรรทัด: precache หน้าออฟไลน์ + ไอคอน,
  cache-first เฉพาะ `/_next/static/` และ `/fonts/`, ทุก navigation ไปเน็ต (ล้ม = หน้าออฟไลน์), ไม่แตะ `/api` `/preview` `/v1`; ชื่อ cache มีเลขเวอร์ชันจาก
  `package.json` → เวอร์ชันใหม่ล้าง cache เก่าใน `activate`; ลงทะเบียนใน client component เล็ก ๆ ใน root layout (production เท่านั้น)
- **ทุก task:** test ก่อนโค้ด, commit ต่อ task, studio 4 คำสั่ง; E2E บน stack rc ของเครื่องทดสอบ (`moking55@192.168.30.26`, ไม่ต้องหยุด main stack)

## Risks and Mitigations

| ความเสี่ยง | ผล | ทางลด |
| --- | --- | --- |
| edit ตารางเปล่าเดิมพังเมื่อมี colspan | สูง | test เดิมของ grid ต้องผ่านไม่แก้ + test ใหม่ทุก edit กับตารางที่มีช่องรวม |
| คลิกเลือกเซลล์ชนกับลาก (dnd-kit) / เลือกบล็อก | กลาง | เลือกเซลล์ใน onClick ของ Frame เดิม (ลากเริ่มที่ handle เท่านั้น); E2E คลิกเซลล์ |
| service worker ค้างไฟล์เวอร์ชันเก่า | กลาง | ไม่ cache หน้า HTML; cache ชื่อตามเวอร์ชัน + ล้างใน activate; E2E/ตรวจหลัง deploy |
| ไอคอนจาก webp ไม่คม/ไม่มีพื้นที่ปลอดภัยของ maskable | ต่ำ | สร้าง maskable แยกที่มีขอบ 20% |
